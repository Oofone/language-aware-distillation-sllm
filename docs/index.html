    2. LLM Prompting and Generation Config

    Raw: content/2_inference_prompt.txt

    2.1 Open-ended Instruction Following Prompt

    
system: You are a helpful assistant. Respond in the language of the user message. 

user: [Speech]

    2.2 Close-ended QA Prompt

    
system: You are a helpful assistant. Respond in the language of the user message. 
Use the following context to briefly answer the question:
Context: [context].

user: [Speech]

    To ensure a fair comparison, we use the same text instruction "Use the following context to briefly answer the question" for evaluating baseline models as well.

    2.3 Generation/Decoding Config

    To keep results reproducible, we do not use sampling when decoding the LLM responses.

    
do_sample: False
max_new_tokens: 256
repetition_penalty = 1.0
length_penalty = 1.0

    For all external baseline models we use the default model generation configuration for inference.

    3. Judging Prompts for Evaluation with MaJ

    Raw: content/3_eval_prompt_closed.txt Raw: content/3_eval_prompt_open.txt

    We follow a similar judging prompt structure to URO-Bench[2]

    3.1 Open-ended (MaJ / GPT-4.1)

    
PRIMARY GOAL:
You are a strict but fair evaluator of the performance of several models in the speech interaction scenario.
The models will receive a speech input from the user, which they need to understand and respond to with a text output.
Your task is to rate the model’s responses based on the provided user input transcription [Instruction] and the model’s output transcription [Response].

SCORING (0-5):
Please evaluate the response on a scale of 1 to 5:
1: The response is largely irrelevant, incorrect, or fails to address the user’s query. It may be off-topic or provide incorrect information.
2: The response is somewhat relevant but lacks accuracy or completeness. It may only partially answer the user’s question or include extraneous information.
3: The response is relevant and mostly accurate, but it may lack conciseness or include unnecessary details that don’t contribute to the main point.
4: The response is relevant, accurate, and concise, providing a clear answer to the user’s question without unnecessary elaboration.
5: The response is exceptionally relevant, accurate, and to the point. It directly addresses the user’s query in a highly effective and efficient manner, providing exactly the information needed.

OUTPUT RULES:
- Output MUST be valid JSON (matching the schema) with keys: "explanation" and "rating".
- Explanation MUST be 1-2 sentences, <= 60 words and always in English.
- Rating MUST be one integer between 0 and 5 (inclusive).

Below are the transcription of user’s instruction and models’ response:

### [Instruction]
{question}

### [Response]
{prediction}

    3.2 Close-ended (MaJ / GPT-4.1)

    
PRIMARY GOAL:
You are a strict evaluator for close-ended QA. 
The reference answer is based on a passage of text and answers are expected to be to the point.

You will be given:
- a Reference Answer
- a Model Answer
- a Question

TASK:
Rate the model's answer based on its alignment with the reference answer, focusing on accuracy and relevance to the reference provided. Be critical on details.
The OBJECTIVE CORRECTNESS of the reference and model answer is not as important as the alignment of the model's answer with the reference answer.
Penalize excessive additional information or deviation from the reference answer, but a few words of additional context is okay.
If the model response is refusing / "cannot decide" / no concrete result, rate 0.

SCORING (0-5):
0: Refusal / "cannot decide" OR completely incorrect/irrelevant vs reference.
1: Minimal alignment, largely misunderstanding or irrelevant.
2: Topic recognized but major divergence from reference.
3: Generally aligns but missing detail or has some inaccuracies.
4: Mostly accurate and relevant, close to reference; could be clearer/more complete.
5: Highly accurate and matches the reference perfectly.

OUTPUT RULES:
- Output MUST be valid JSON (matching the schema) with keys: "explanation" and "rating".
- Explanation MUST be 1-2 sentences, <= 60 words and always in English.
- Rating MUST be only 1 integer between 0 and 5 (inclusive).

Below are the reference answer, model's response, and the question:

[Reference Answer]
{reference}

[Model Answer]
{prediction}

[Question]
{question}

    4.2 Open-Ended Evaluation

    English samples are obtained from the AudioBench [4] dataset. Indonesian samples are translated from AudioBench by a native speaker, and synthesized using state-of-the-art TTS system. Chinese samples are obtained from URO-Bench [2].

    Sample 1 (English)
    Raw: audio/4_en_hermes_bad_open.wav

    Question (Audio): Suppose in a certain market, the probability that a customer buys a product is 0.6 and the probability that the customer buys another product is 0.4. What is the probability that the customer buys both products?
    Model Prediction: 

    
To find the probability that a customer buys both products, we need to multiply the individual probabilities since these are independent events.

Given:
- Probability of buying Product A = 0.06
- Probability of buying Product B = 0.04

Probability of buying both products = 0.06 × 0.04 = 0.0024

So, the probability that a customer buys both products is 0.0024 or 0.24%.

    MaJ Score: 2.0
    MaJ Explanation:The response incorrectly uses 0.06 and 0.04 instead of the given probabilities 0.6 and 0.4, leading to a wrong answer. The explanation of independence is correct, but the calculation is based on incorrect values.

    Sample 2 (English)
    Raw: audio/4_en_hermes_good_open.wav

    Question (Audio): What is the probability of rolling a 4 on a fair dice?
    Model Prediction: 

    
The probability of rolling a four on a fair six-sided die is 1/6, or approximately 16.67%.
This is because there is only one favorable outcome (rolling a 4) out of six possible outcomes (rolling 1, 2, 3, 4, 5, or 6).

    MaJ Score: 5.0
    MaJ Explanation:The response is accurate, concise, and clearly explains the probability calculation for rolling a 4 on a fair die.

    Sample 3 (Indonesian)
    Raw: audio/4_id_alpaca_open.mp3

    Question (Audio): Hitung luas segitiga dengan panjang 15 dan lebar 30?
    Model Prediction: 

    
Luas segitiga dengan panjang 15 dan lebar 30 adalah:

Luas = (panjang × lebar) ÷ 2
= (15 × 30) ÷ 2
= 450 ÷ 2
= 225 satuan persegi

Jadi, luas segitiga tersebut adalah 225 satuan persegi.

    MaJ Score: 5.0
    MaJ Explanation:The response correctly applies the triangle area formula and provides a clear, step-by-step calculation, directly answering the user's question.

    Sample 4 (Chinese)

    Question (Audio): 鲍勃有两个儿子。约翰和杰伊。杰伊有一个兄弟和父亲。父亲有两个儿子。杰伊的兄弟有一个兄弟和一个父亲。杰伊的兄弟是谁。
