TL;DR

Distillation-based Speech LLMs train well in English from ASR data alone, but degrade when scaled to many languages because a single static query sequence in the shared projector causes language interference. We replace it with a language-gated query bank: one learnable query sequence per language, selected or mixed by a small gating network inside a Q-Former. This gives +14% on instruction following and +32% on our new Audio-MLQA benchmark, trained on 5,870 hours of ASR-only data with the speech encoder and the LLM kept frozen throughout.

Method

A query bank and a gating network, added to an otherwise frozen pipeline.

Query bank and gating

Instead of one static query sequence, we keep a bank B = {Q(k)} with one learnable sequence per language. A gating network Gφ pools the speech embeddings into language logits g, which either mix the queries (π = softmax(g)) or select a single one (k* = argmax g). Hard selection uses a straight-through estimator so the choice stays discrete at inference while gradients still reach the gate.

Hard selection consistently beats soft mixing. Averaging queries reintroduces exactly the interference we set out to remove — dominant languages leak into the mixture and wash out the lower-represented ones.

Training objective

Three terms, combined as ℒ = λINℒIN + λOUTℒOUT + λLIDℒLID:

  • ℒLID — cross-entropy on the gating network's language logits.
  • ℒIN — L2 between the projected audio tail and the transcript head. Coarse prefix alignment, so no frame-level alignment is needed.
  • ℒOUT — L2 between the frozen LLM's final hidden states under speech versus transcript conditioning.

Early in training the query bank is randomly initialised and the gate has nothing useful to route on, so scheduled teacher forcing routes on the true language label with probability ptf, cosine-annealed from 1 to 0 and reaching zero at 50% of training steps.

Audio-MLQA

A multilingual spoken question-answering benchmark, released with this paper.

There is very little established evaluation for multilingual speech understanding, so we built one. Audio-MLQA takes textual context and questions from MLQA and synthesises the spoken questions with state-of-the-art TTS at 44.1 kHz. It tests whether a model can align a spoken question with key words and phrases in a textual context — a closed-ended task, complementary to open-ended instruction following.

What the numbers say

  • Indonesian gains most. 3.04 → 3.71, a +22% jump over the matched ML-DiVA baseline. The lowest-represented language in the pool is exactly where removing interference pays off, which is the core claim of the paper.
  • +14% average over ML-DiVA on open-ended instruction following.
  • Audio-MLQA: 3.96, which is +32% over SeaLLMs-Audio and +31% over Qwen2-Audio, and within 4% of the text-only topline of 4.14.
  • Chinese is the honest exception. Zero-shot models still lead there — it is the most distant language from the rest of our training pool, and the one place our approach does not win.

Raising the query length L from 64 to 256 cuts the input distillation loss by 89%, so capacity matters for the phonetic–semantic mapping. Both gating architectures exceed 94.9% language-ID accuracy, which tells us routing accuracy is not the bottleneck — the benefit comes from having separate queries at all, not from a particular gate design.
